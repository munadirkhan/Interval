# Interval — 90 second demo script

Read this off a second screen while you drive the emulator. Natural pace, don't rush.
Roughly 150 words, which lands around 85–95 seconds with pauses.

---

**[Cold launch — dark splash, Today screen]**

> This is Interval.
>
> I have about four hundred screenshots of lecture slides on my phone. I've opened maybe six of them.

**[Tap Generate → type a topic → orb spins → drafts appear]**

> So instead of making cards, you just describe a topic. It builds the set — flashcards, multiple choice, true-false. Nothing gets saved until you accept it, so a wrong answer costs one tap to reject.

**[Add cards → Review now → flip a card]**

> Then it schedules them. One day, three, seven, thirty, ninety. The next interval is printed right on the button, so the algorithm isn't a mystery you have to trust.

**[Quiz card → pick the wrong answer → tap Explain this]**

> Get one wrong, and it explains it right there. Which is the one moment you actually want an explanation.

**[Answer correctly → XP burst]**

> Get it right, and you're paid for it.

**[Add past the card limit → paywall → TEST VALID PURCHASE → Pro unlocks]**

> Free stops at five cards. Pro is a single RevenueCat entitlement — and it's tied to your profile, not your install. Delete the app, reinstall, and it comes back.

**[Stats screen with the heatmap]**

> I'd never written a line of Kotlin before this week. Built solo in three days.

## Recording notes

- **One pass, screen + mic**, in Clipchamp or OBS. No editing needed.
- Record the **emulator window only**, not the whole desktop — no Android Studio, no taskbar.
- **Close Logcat** and anything with notifications that could pop mid-take.
- Have the topic text **pre-copied** so you paste instead of typing on camera.
- If generation is slow, that's fine — the orb is worth two seconds of screen time.
- **Two minutes is a hard cap** and judges aren't required to watch past it. Front-load: AI generation and the review loop are the strongest 30 seconds, so don't bury them.
- No copyrighted music. Silence is fine.
